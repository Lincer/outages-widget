# Віджет графіків відключень у м. Хмельницький

Невеликий віджет для iOS, який показує графік погодинних відключень для вибраної підчерги. Дані завантажуються з сайту [Хмельницькобленерго](https://hoe.com.ua/page/pogodinni-vidkljuchennja); якщо оновити їх не вдається, віджет використовує збережені дані. Натискання на віджет відкриває сторінку з графіками.

## Встановлення

1. Встановіть [Scriptable](https://apps.apple.com/us/app/scriptable/id1405459188) на iPhone.
2. Завантажте скрипт на iPhone:
   1. Відкрийте [файл `Outages.js` на GitHub](https://github.com/Lincer/outages-widget/blob/main/Outages.js).
   2. На сторінці файлу натисніть **Raw**. Відкриється текст скрипту.
   3. Натисніть кнопку **Поділитися** у браузері, виберіть **Зберегти у Файли** (*Save to Files*).
   4. У вікні збереження відкрийте **iCloud Drive** → **Scriptable** і натисніть **Зберегти**. Не перейменовуйте файл: він має називатися `Outages.js`.

   Якщо папки **Scriptable** ще немає, спершу відкрийте встановлений застосунок Scriptable і дозвольте йому використовувати iCloud Drive, а тоді поверніться до збереження файлу.
3. Додайте віджет Scriptable на домашній екран: затисніть порожнє місце, натисніть **+**, знайдіть Scriptable і виберіть розмір віджета.
4. Натисніть на доданий віджет або затисніть його й виберіть **Редагувати віджет**. У полі **Script** виберіть `Outages`, а в полі **Parameter** введіть номер підчерги, наприклад `3.1`.

Готово! Щоб змінити підчергу, відредагуйте **Parameter**. Щоб стежити за кількома підчергами, додайте окремий віджет для кожної. Для зворотного графіка (показувати коли світло буде, а не коли його не буде) додайте до параметра `є`, наприклад `3.1є`.
